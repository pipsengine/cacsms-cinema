## 3. Key excerpts — API route + repository behavior

### Route handlers (summary)
1. **List** — workspace-scoped register of projects LEFT JOIN briefs, ordered by brief urgency then `UpdatedAt`.
2. **Get** — project + brief + child collections + versions; 404 if project not in workspace / archived.
3. **Save (PUT)** — upsert draft brief from project defaults; replace optional child arrays; activity `BRIEF_SAVED` / stage `STRATEGY_BRIEF`; returns full get payload.
4. **Submit** — requires existing brief (409 otherwise); inserts `ContentBriefVersions` snapshot; sets brief `IN_REVIEW`; inserts `ProjectApprovals` (`StageKey='STRATEGY_BRIEF'`, `ApprovalType='Content Brief Approval'`, `PENDING`); activity `BRIEF_SUBMITTED`.
5. **Decision** — requires `IN_REVIEW` (409 otherwise).  
   - **RETURN:** version + brief → `RETURNED`; pending approval → `RETURNED`; activity `BRIEF_DECISION`.  
   - **APPROVE:** version/brief → `APPROVED`; complete `STRATEGY_BRIEF` stage execution; ensure `OPPORTUNITY_DISCOVERY` is `NOT_STARTED`; insert **`ProjectHandoffs`** (`FromStageKey='STRATEGY_BRIEF'`, `ToStageKey='OPPORTUNITY_DISCOVERY'`, `OutputType='Approved Content Brief'`, `OutputReference='CONTENT_BRIEF'`, `Status='READY'`); insert **`ProjectVersions`** type `CONTENT_BRIEF`.

### Repository signatures (exact)
