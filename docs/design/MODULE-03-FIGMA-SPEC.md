# Module 03 — Figma Design Specification

## Visual language
White/light neutral canvas, white operational surfaces, subtle `#E4E7EC` borders, 10–14px radii, minimal shadows and restrained blue accent. Cards are used for hierarchy; governed records use enterprise tables.

### Status system
- Grey — Not Started
- Amber — In Progress
- Green — Completed / Approved
- Blue — Awaiting Approval
- Purple — Paused / AI processing
- Red — Blocked / Failed

## Content Projects
Header → KPI strip → search/filter toolbar → enterprise project register. Each row exposes project code, title, platform/type/category, current stage, progress, owner, autonomy, priority, deadline and status.

## Create Project
Two-column wizard. Left rail shows five stages and state. Main workspace uses grouped enterprise forms, not card-heavy consumer UI. Final review explicitly previews the handoff to Module 04.

## Project Workspace
Title/status/priority header → project metadata → progress card → persistent tabs: Overview, Workflow, Assets, Versions, Approvals, Activity.

Overview prioritizes Next Required Action and Handoff Chain. Workflow exposes Input → Output → Status at every stage. Assets/Versions/Approvals/Activity use tables/timelines for auditability.
