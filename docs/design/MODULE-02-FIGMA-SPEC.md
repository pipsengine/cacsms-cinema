# Module 02 — Figma Design Specification

## Visual direction
Enterprise SaaS, white/light-neutral canvas, white cards, 1px neutral borders, restrained shadows, blue primary actions, compact data density and clear status chips.

### Status colors
- Not Started: grey
- In Progress: amber
- Completed: green
- Awaiting Approval: blue
- Paused / AI processing: purple
- Blocked / Failed / Critical: red

## Command Center
Header, six KPI cards, production pipeline board, My Work panel, AI agent activity, notifications, publishing schedule, system health strip and right-side project lifecycle drawer.

## My Work
Summary strip, status tabs, search/filter toolbar and enterprise work-item table with project/stage context, priority, status, due date and actions.

## Notifications
Left category rail and right chronological event feed. Unread items use subtle blue inset accent. Severity icon blocks preserve the global color language.

## Responsive behavior
Desktop sidebar persists. At tablet widths dashboard cards collapse to one/two columns and tables become horizontally scrollable. At mobile widths controls stack and the project lifecycle drawer becomes full width.
