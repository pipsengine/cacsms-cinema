# Design System Foundation

## Visual language

- Page backgrounds: white or very light neutral
- Cards: white, subtle border, restrained shadow, 10–16px radius
- Tables: enterprise density, strong column hierarchy, sticky headers where useful
- Forms: grouped sections with clear labels and validation states
- Sidebar: white, grouped by production responsibility
- Primary accent: professional blue

## Global status colors

- Not Started: neutral grey
- In Progress: amber
- Completed: green
- Awaiting Approval: blue
- Failed / Blocked: red
- AI Processing: purple
- Paused: slate

## Standard page anatomy

`Breadcrumb → Title / Project Context → Status & Primary Actions → KPI/Context → Main Workspace → Output/Handoff → Activity`
